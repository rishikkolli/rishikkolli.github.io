      How this works

      • Sources: public, key-less Greenhouse, Lever and Ashby job-board APIs for employers with a public track record of H-1B filings. A GitHub Action fetches them daily at 7:00 AM ET and commits the result, so the page is static and hosted free on GitHub Pages.
      • Filters: full-time only; early-career to mid-level titles (senior, staff, principal, manager, intern and contract roles excluded); target cities or US-remote; postings that say they cannot sponsor, require citizenship, or require a security clearance are removed.
      • Sponsorship: "Sponsorship mentioned" means the posting text explicitly mentions visa sponsorship. "Not stated" is common and not a no, but confirm with the recruiter on the first call.
      • Interview notes are typical loops for that kind of company, drawn from public candidate reports, not insider info. Always check recent reports and ask the recruiter.
      • Data handling: all posting text is treated as untrusted. It's stripped of HTML on fetch and only ever rendered as plain text, links must be https, and a strict Content-Security-Policy blocks inline and third-party scripts.
